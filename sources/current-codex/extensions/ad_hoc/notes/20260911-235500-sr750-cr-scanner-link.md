# SR-750 TCP 扫码通讯确认

- 2026-09-11：现场 SR-750 配置确认命令端口和数据端口 1 使用 Ethernet/9004、ASCII、CR；远程电脑为 `192.168.2.100`，扫码枪为 `192.168.2.10`。
- UI 原来使用 CRLF，导致扫码枪连接反复断开；已统一改为单个 `CR`，远程 UI 重启后 TCP 会话连续保持 `ESTABLISHED`，由当前 UI 进程持有。
- 若现场仍无条码进入 UI，只需继续核对数据端口 1 的连接模式：扫码枪作为 server 时目标地址应为 `0.0.0.0`；作为 client 时目标地址应为远程电脑 `192.168.2.100`。
