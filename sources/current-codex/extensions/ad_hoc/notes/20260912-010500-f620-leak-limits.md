# ATEQ F620 泄漏上下限

- 2026-09-12：F620 泄漏程序中 `Test FAIL` 是测试件泄漏上限；`Ref. FAIL` 是参考件拒绝级别，现场中文参数指导书将其作为下限，设为 0 表示不启用下限判定。
- Modbus 直接访问：先向 `0x6000` 写入程序号减一；`Test FAIL` 写 `0x603C`、读回 `0x203C`；`Ref. FAIL` 写 `0x603E`、读回 `0x203E`。数值按长整型固定小数 `x1000` 传输，例如 1.50 写 1500。
- `Max FILL`/`Min FILL` 是充气压力上下限，不是泄漏量上下限；流量单位还需同步设置 `REJECT CALC.` 与 `VOLUME` 参数。
