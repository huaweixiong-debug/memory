# 2026-09-14 网易UU远程打不开修复

- 现象：UU远程（Netease GameViewer）双击后无窗口、静默退出（launcher exit 0、无子进程、无崩溃日志）。
- 根因：9月7日与9月13日 17:51 两次就地自动升级失败/中断，安装目录版本状态混乱：名为 4.40.0.1780 的版本目录内实际是 4.38.3.9325 主程序（FileVersion 确认），注册表 Version=4.38.3.9325，根目录 Service 还是 4.37 时代文件，另留有 bak 备份。启动器校验不过即静默退出。
- 修复：运行安装目录 setup/ 里官方 UURemote_Setup_4.40.0.1780 安装包做修复安装（约10秒完成），新布局改为 bin\ 目录，注册表归位 4.40.0.1780，主窗口恢复。
- 排查技巧：安装目录 log/*\/Sentry/*.run/__sentry-event 是 msgpack 可读（release=版本号、level=error）；升级日志 log/upgrade/Log 的 .txt 是 UTF-16LE，.slog 是加密格式读不了；用 WMI Win32_ProcessStartTrace 可确认启动器是否拉起子进程。
