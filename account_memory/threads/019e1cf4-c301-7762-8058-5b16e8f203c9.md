## 现象解释

这是两个**不同的 Codex 配置实例**：

- **实例 A**（原始模型，比如 DeepSeek V4 Pro）：有它自己的聊天历史
- **实例 B**（`cc switch` 切换后的模型，比如 GPT-5.4）：有它自己的聊天历史

`codex cc switch` 实际上创建了**独立的配置/会话空间**，所以两边的聊天记录是分开存储的。当你切回去的时候，旧配置的聊天记录还在，新配置的也还在，但它们互不相通。

## 原因

`cc switch` 本质上是绑定到一个**不同的 Codex 配置 profile**，每个 profile 的线程（聊天记录）存储路径是独立的。所以切换模型 = 切换到不同的 profile，自然看不到另一个 profile 的聊天记录。
