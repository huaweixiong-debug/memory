**Fix 1 — 不再丢弃版本不匹配的轮次输出** (`tui_gateway/server.py:1464`)
- **之前**：版本不匹配时整轮对话输出被丢弃，用户看到回复但下一轮 agent 全忘了
- **现在**：将 agent 输出 merge 进当前 history，保证模型记住自己刚说的话

**Fix 2 — 压缩阈值 0.50 → 0.70** (`agent/context_compressor.py:282`)
- **之前**：用满一半上下文就开始有损压缩，长对话中很快就丢失细节
- **现在**：用满 70% 才触发压缩，给用户更多对话空间

**Fix 3 — 预检查压缩回退从 3 次 → 1 次** (`run_agent.py:8908`)
- **之前**：单轮可以连续压缩 3 次，每次丢弃更多上下文
- **现在**：单轮最多压缩 1 次，避免过度压缩

**Fix 4 — `_compress_session_history` system prompt 兜底** (`tui_gateway/server.py:497`)
- **之前**：`_cached_system_prompt` 为空时传入空字符串，导致 compression 后 system prompt 丢失
- **现在**：fallback 到 `ephemeral_system_prompt`，保证 personality/tone 不丢失
