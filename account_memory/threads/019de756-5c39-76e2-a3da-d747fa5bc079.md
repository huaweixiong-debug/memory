## 🔍 根本原因：iLink Bot API 的对话不走普通同步通道

你的 Hermes 用的是 **iLink Bot API**（`ilinkai.weixin.qq.com`），这是微信官方的**机器人接口**，和普通聊天走的是**不同的同步机制**。

```
普通聊天：手机 ↔ 微信云同步 ↔ 电脑  ✅
机器人聊天：iLink API → Hermes → 回复  ❌ 不同步到电脑
```

## 📋 具体原因

1. **iLink Bot 认证方式不同**
   - 普通聊天：`AuthorizationType: normal`
   - 机器人：`AuthorizationType: ilink_bot_token`

2. **会话类型不同**
   - 普通聊天：走微信标准同步通道
   - 机器人：走 iLink Bot 专用通道，**不会同步到电脑微信**

3. **消息流转路径**
   - 你发消息给 clawbot → 微信服务器 → iLink API → NAS上的 Hermes → 回复
   - 这个对话**只在手机微信的"服务通知"或"机器人"里**，不会出现在电脑微信的聊天列表

## 💡 解决方案

**方案一：在电脑微信搜索 clawbot**
- 电脑微信搜索 clawbot 的名字
- 找到后点击进入，可以看到聊天记录
- 但需要手动搜索，不会自动出现在聊天列表

**方案二：用 Hermes 网页版查看**
- 在电脑浏览器访问 Hermes 的 Web 界面
- 可以看到所有微信聊天记录

**方案三：Hermes 转发到普通聊天**
- 让 Hermes 把 clawbot 的回复转发到你的普通微信聊天
- 这样电脑微信就能收到了

## 🎯 结论

**这不是 Tailscale 的问题**，而是 iLink Bot API 的设计特性。机器人对话不会自动同步到电脑微信，因为走的是不同的同步通道。
