### 助手结果摘录 1

我没有找到本地有“Offer 1M-context variant”那套配置的落盘 JSON，说明那张设置页很可能不是直接写 `~/.claude/settings.json` 的同一套机制。现在我查一下 Claude Code 二进制里支持的 capability 名字，看看有没有专门让自定义网关模型声明 1M 能力的隐藏字段。

### 助手结果摘录 2

我看到了 Claude Code 内部 picker 的逻辑：一旦设置了 `ANTHROPIC_DEFAULT_SONNET_MODEL` / `OPUS_MODEL`，它就把 `sonnet[1m]` / `opus[1m]` 那两个内置 1M 项短路掉了。这不是你操作问题，是它的实现路径有这个分叉。

我现在换一种更贴合它机制的映射：用 `sonnet` 显示 `flash`，`opus` 显示 `pro`，`haiku` 借来显示 `flash 1M`，再用唯一的 `ANTHROPIC_CUSTOM_MODEL_OPTION` 显示 `pro 1M`。这样正好凑齐你要的四个可选项。

### 助手结果摘录 3
