### 助手结果摘录 4

好的，让我仔细分析一下你遇到的这些现象。

---

**问题 1：Hermes 失忆（记不住上下文）**

可能原因：

- **上下文窗口太短**：Hermes 调用的底层模型可能限制了最大的上下文 token 数。一次对话结束后，之前的消息没有被保留在下一轮的上下文里。
- **会话未持久化**：Hermes 可能没有开启会话记忆功能，或者每次对话是独立的新 session。
- **配置中的 `max_tokens` 或 `context_length` 过小**，导致它即使记住了也只保留了很短的历史。

**问题 2：Hermes 调用 Codex 出现 Claude**

这个比较关键。Codex CLI 本身是模型无关的——它可以通过配置对接不同的大模型（OpenAI、Claude 等）。所以你看到的可能情况是：

- Hermes 内部把它们（Hermes、Codex）搭成了一个调用链，调用链末端的 Codex 实例配置的是 Anthropic Claude，所以你对话时看到的是 Claude。
- 你的 Codex CLI 配置里 `provider` 可能设成了 Anthropic。
