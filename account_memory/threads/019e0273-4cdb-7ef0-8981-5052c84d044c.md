## 这台电脑能用 DeepSeek 的秘密就在 3 个文件：

### 文件 1：`%USERPROFILE%\.codex\config.toml`

```toml
model_provider = "lmstudio"       # ← 关键！告诉 Codex 用本地代理
model = "deepseek-v4-pro"         # ← 模型名
disable_response_storage = true   # ← 关闭云端存储
```

**别的电脑：** 这里一般是 `model_provider = "openai"` 和 `model = "gpt-5.5"`，改过来就行。

---

### 文件 2：`%USERPROFILE%\.codex\deepseek.env`

```
DEEPSEEK_API_KEY=sk-你的key
```

**别的电脑：** 这个文件不存在，需要你自己创建。API Key 去 [platform.deepseek.com](https://platform.deepseek.com) 拿。

---

### 文件 3：Windows 用户环境变量 `CODEX_OSS_BASE_URL`

```
CODEX_OSS_BASE_URL = http://127.0.0.1:17777/v1
```

**这个最容易被忽略！** 这是用户级环境变量（不是系统变量），在 PowerShell 中执行一次就永久生效：
```powershell
[Environment]::SetEnvironmentVariable("CODEX_OSS_BASE_URL", "http://127.0.0.1:17777/v1", "User")
```

---
