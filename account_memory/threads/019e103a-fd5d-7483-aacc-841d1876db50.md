## 诊断结果

你的 PyCharm 2026.1.1 闪退的根本原因是 **Java 虚拟机内存不足 (Out of Native Memory)**，而且这个问题从 2025 年 3 月就开始了，所有的 crash log 都是同一个错误：

> `There is insufficient memory for the Java Runtime Environment to continue.`

### 关键数据

| 项目 | 数值 |
|------|------|
| 物理内存总量 | **15.8 GB** |
| 当前已用 | **12.1 GB** (76%) |
| 虚拟内存(Pagefile) | **0 MB** — **未启用！** |
| JVM 堆设置 | `-Xmx2048m` (2 GB) |
| 失败操作 | `mmap` 尝试分配 **231 MB** 失败 |

### 根本原因

1. **虚拟内存 (Pagefile) 被禁用或设为 0** — 这是最关键的问题。Windows 运行了大量进程（Edge 浏览器就占用了 2GB+，加上 Codex、NVIDIA Overlay、AweSun 等），15.8 GB 物理内存在这些进程下基本已经用尽。没有 pagefile 就没有任何后备方案。

2. JVM 启动时首先分配 256 MB (`-Xms256m`)，然后尝试扩展到 2 GB (`-Xmx2048m`)，同时还需要额外的 native 内存（包括 CEF 浏览器组件、JIT 编译器代码缓存等），在剩余内存不足且没有 pagefile 的情况下，JVM 直接崩溃。

## 解决方案（按优先级排序）

### 🔴 方案 1：启用 Windows 虚拟内存（推荐，治本）

以管理员身份打开 PowerShell，执行：

```powershell
# 设置为系统管理的大小（推荐）
$pagefile = Get-CimInstance -ClassName Win32_PageFileSetting
if (-not $pagefile) {
    # 如果未设置，创建自动管理的 pagefile
    $sys = Get-CimInstance Win32_ComputerSystem
    $sys.AutomaticManagedPagefile = $true
    Set-CimInstance -InputObject $sys
}
```

或者手动设置：
1. 右键「此电脑」→ 属性 → 高级系统设置 → 性能设置 → 高级 → 虚拟内存 → 更改
2. 勾选「自动管理所有驱动器的分页文件大小」，或手动设置为 **4096 MB - 8192 MB**
3. 重启电脑
