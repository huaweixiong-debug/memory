## 部署步骤

### 1. 关闭 Codex 桌面版
config.toml 被 Codex 进程锁定，必须先退出。

### 2. 复制配置文件
打开 PowerShell：
```powershell
Copy-Item "D:\Codex\config-profiles.toml" "$env:USERPROFILE\.codex\config.toml" -Force
```

### 3. 填写 Mimo API Key
编辑 `D:\Codex\mimo-codex-proxy\mimo.env`，把 API Key 和 Base URL 改成你自己的：
```
MIMO_API_KEY=sk-你的实际Key
MIMO_BASE_URL=https://api.minimax.chat/v1     # 或你用的 Mimo API 地址
```

DeepSeek 的 Key 已配置好 (`D:\Codex\codex_deepseek_setup\deepseek.env`)。

### 4. 启动代理
双击 `D:\Codex\start-all-proxies.bat`（两个代理都会后台启动）。

### 5. 重新启动 Codex 桌面版

## 切换模型

Codex 桌面版中通过 **设置 → Profiles** 选择：

- **gpt55** → GPT-5.5（OpenAI 直连，无需代理）
- **gpt54** → GPT-5.4（OpenAI 直连）
- **deepseek** → DeepSeek V4 Pro（走 17777 代理）
- **mimo** → Mimo V2.5 Pro（走 17778 代理）

也可以命令行启动：`codex -p deepseek` / `codex -p mimo`
