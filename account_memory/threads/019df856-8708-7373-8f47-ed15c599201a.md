## 复刻 DeepSeek 功能需要复制的文件

要让另一台电脑也能用 DeepSeek，核心需要复制以下 **5 个关键文件**：

### 🔑 必须复制的核心文件

| 文件 | 作用 |
|------|------|
| **`config.toml`** | 核心配置，指定 `model_provider = "lmstudio"`、`model = "deepseek-v4-pro"`、`model_reasoning_effort = "high"` |
| **`deepseek.env`** | DeepSeek 相关的环境变量（API key / endpoint 等） |
| **`.env`** | 代理配置（HTTP_PROXY / HTTPS_PROXY） |
| **`auth.json`** | OpenAI 账号认证信息（ChatGPT Plus 订阅 token） |

### ⚠️ 可能需要（视情况而定）

| 文件/目录 | 作用 |
|-----------|------|
| **`plugins/cache/`** 整个目录 | 安装的插件缓存（Documents、Presentations、Spreadsheets、Browser Use、GitHub、Gmail） |
| **`skills/`** 整个目录 | 系统技能和运行时技能 |

### ❌ 不需要复制的

- `logs_2.sqlite`（300MB+，日志数据库）
- `state_5.sqlite` / `state_5.sqlite-wal`（会话状态）
- `sessions/`（历史会话记录）
- `log/`（日志文件）
- `tmp/`、`.tmp/`、`cache/`（临时/缓存，会自动重建）
- `sandbox.log`、`history.jsonl`、`session_index.jsonl`
- `.codex-global-state.json` 及其 tmp 文件
