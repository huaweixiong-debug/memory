你可以按这个顺序处理：

1. 两台电脑都重启 Tailscale

```powershell

```

2. 重新测试

```powershell

tailscale ping 100.98.33.48
```

3. 如果还丢包，把 `100.98.33.48` 那台电脑的 Tailscale 也升级到最新版，或者先退出再重新登录 Tailscale。

4. 如果你只是要远程桌面，不用太纠结普通 ping；关键看端口是否通：

```powershell
Test-NetConnection 100.98.33.48 -Port 3389
```

目前防火墙问题已经解决，剩下是两端网络质量/Tailscale 直连稳定性问题。最有效的第一步就是两边都 `Restart-Service Tailscale`。
