```text
from pathlib import Path
```
然后回车。

3. 在下一行插入  
按 `o`，然后把下面这段粘进去：

```python
_ORIG_PATH_EXISTS = Path.exists
_ORIG_PATH_IS_FILE = Path.is_file
_ORIG_PATH_RESOLVE = Path.resolve

def _hermes_safe_path_exists(self, *args, **kwargs):
    try:
        return _ORIG_PATH_EXISTS(self, *args, **kwargs)
    except (PermissionError, OSError):
        return False

def _hermes_safe_path_is_file(self, *args, **kwargs):
    try:
        return _ORIG_PATH_IS_FILE(self, *args, **kwargs)
    except (PermissionError, OSError):
        return False

def _hermes_safe_path_resolve(self, *args, **kwargs):
    try:
        return _ORIG_PATH_RESOLVE(self, *args, **kwargs)
    except (PermissionError, OSError):
        return self

Path.exists = _hermes_safe_path_exists
Path.is_file = _hermes_safe_path_is_file
Path.resolve = _hermes_safe_path_resolve
```

4. 保存退出  
先按 `Esc`，再输入：
```text
:wq
```
然后回车。

### 助手结果摘录 5

先别继续改 `prompt_builder.py` 了，真正的根因更像是权限，不是代码。

你日志里这两点连起来很关键：

- `/workspace` 之前是 `drwxr-x--- root uucp`
- Hermes 启动时会 `Dropping root privileges`

也就是说，Hermes 真正处理微信消息时已经不是 `root` 了，它没权限穿过 `/workspace`，所以一查：

- `/workspace/.git`
- `/workspace/.hermes.md`
- `/workspace/AGENTS.md`
- `/workspace/CLAUDE.md`

就报 `Permission denied`

